Areas
System
Right-drag looks. WASD moves. Alt+left-drag orbits. Middle-drag pans. Scroll zooms.

Settings

Albedo uploads as BC blocks. Turn this off, or open ?textures=bitmap, to use the JPEG and PNG instead.

Shortcuts

Fly is the camera. Orbit and pan are modifiers. Esc or a click outside closes this list.

Search

Actors in this scene, scene files, and editor commands. Enter selects and frames an actor, opens a scene, or runs the command.

Add an actor

Names come from Pack/Actor in the dump. The new actor is placed at the camera target.

Build the mod

Changed placement files are re-encoded with the dump’s zstd dictionary. The size table is only raised. The dump’s own files are not modified.

Save Longshot mod writes patches for the edits that differ from the dump and installs them into the test game’s mods/local folder. The default game is ~/Games/Longshot/mod-test. Set OCARINA_FORGE_GAME to use another install.
